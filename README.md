# ✅ Docheck: Verify Smart

An AI-powered document and signature verification system designed to automate identity and content validation workflows with high precision. This solution integrates deep learning, OCR, and large language models to provide intelligent and secure document verification.

## 🧠 Key Features

- ✍️ **Signature Verification** using VGG16 Convolutional Neural Network (CNN)  
- 🧾 **Document OCR Extraction** with Tesseract OCR for structured data parsing  
- 🧼 **Image Preprocessing** using OpenCV for noise reduction, alignment, and clarity  
- 🤖 **LLM Integration** with Gemini for intelligent data interpretation and semantic comparison  
- 🔐 **Authentication & Security** via JWT-based login and session management  
- 📁 **MongoDB Storage** for storing extracted data, user info, and verification logs  
- ⚙️ **FastAPI-Powered Backend** for scalable API-based architecture  
- 🌐 **Node.js Utility Services** for auxiliary operations and routing

## 🛠️ Tech Stack

- **Deep Learning**: VGG16 (Keras/TensorFlow or PyTorch)
- **Image Processing**: OpenCV  
- **OCR Engine**: Tesseract OCR  
- **Language Model**: Gemini LLM (via API)  
- **Backend Framework**: FastAPI (Python)  
- **Authentication**: JWT (JSON Web Token)  
- **Database**: MongoDB  
- **Support Scripts / Utilities**: Node.js
